# Design brief

- Purpose: customer-service workspace for handling conversations and inspecting persisted task state.
- Context: operational analyst workspace, with chat as the primary task and history/state as supporting panels.
- Tone: dense analyst workspace, calm ink-and-paper neutrals with a restrained rust accent.
- Differentiator: real business records render as compact cards; the conversation timeline and live state inspector stay visible together.
- Constraints: code-native HTML/CSS/JS, API at 8001, static output at 8080, desktop two-column and mobile single-column disclosure; no decorative motion or external images.
